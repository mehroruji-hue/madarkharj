# مادرخرج (نسخه‌ی ۰.۱)

وب‌اپ نصب‌شدنی (PWA) برای تقسیم خرج دورهمی. [ایده‌ی ۵](../ideas/05-madar-kharj.md) رو ببینید.

## امکانات
- ثبت افراد (با شماره کارت اختیاری) و خرج‌ها، با امکان مشخص کردن اینکه هر خرج سهم چه کسانیه
- **مهمون همراه:** هر نفر می‌تونه همراه داشته باشه و سهمش چند برابر حساب بشه
- **پرداخت نقدی بین اعضا:** پولی که همون‌جا نقدی یا کارت‌به‌کارت رد و بدل شده، از سهم کم می‌شه
- محاسبه‌ی سهم و بدهی هر نفر
- **پلن پرداخت:** تا جای ممکن هر نفر فقط یک بار پرداخت می‌کنه. مبالغ به‌صورت پیش‌فرض **دقیق**‌ن، و رند کردن یه گزینه‌ی اختیاریه که اختلافش قبل از روشن کردن نمایش داده می‌شه
- اشتراک‌گذاری با لینک: گیرنده هیچی نصب نمی‌کنه، اسمش رو می‌زنه و سهمش رو می‌بینه
- کپی شماره کارت با یک کلیک، و دکمه‌ی «پرداخت کردم» که پیام آماده رو در واتساپ باز می‌کنه
- **یادآوری با پیامک:** دستی و رایگان (اپِ پیامکِ گوشی با متن آماده باز می‌شود) یا خودکار با پنل پیامکی خود کاربر
- **یادآوری با ربات تلگرام:** بدون سرور، با ربات خودِ کاربر (توکن فقط روی همان دستگاه می‌ماند)
- کار آفلاین و ذخیره‌ی داده‌ها فقط روی خود دستگاه

## منطق تسویه (`js/settle.js`)
1. موجودی هر نفر = چقدر خرج کرده − سهمش
2. تلاش برای پلنی که **هر بدهکار فقط یک پرداخت** داشته باشه
3. گرد کردن با **تحمل** کار می‌کنه، نه واحد ثابت: کاربر می‌گه حداکثر چقدر اختلاف قبوله (۰، ۱۰۰، ۱۰۰۰ یا ۵۰۰۰ تومان) و برنامه در همون محدوده **گردترین** عدد رو پیدا می‌کنه (۱۹۹٬۴۰۰ با تحمل ۱۰۰ ← ۱۹۹٬۵۰۰، با تحمل ۱۰۰۰ ← ۲۰۰٬۰۰۰)
4. اختلاف هیچ‌کس از تحمل بیشتر نمی‌شه؛ اگه کسی دو پرداخت داشته باشه، بودجه‌ی گرد کردن کم می‌شه تا این تضمین حفظ بشه
5. مبلغ دقیق همیشه زیر مبلغ گردشده نمایش داده می‌شه
6. اگه «هر نفر یک پرداخت» ممکن نشد، روش حریصانه

## اجرا روی کامپیوتر
```bash
python -m http.server 5174 -d madarkharj
```
بعد `http://localhost:5174` رو باز کنید.

## ربات تلگرام (`js/telegram.js`)
مادرخرج سرور نداره، پس مرورگر مستقیم با Bot API تلگرام حرف می‌زنه:
- کاربر با @BotFather ربات خودش رو می‌سازه و توکن رو وارد می‌کنه (فقط در `localStorage` همون دستگاه، و هیچ‌وقت داخل لینک اشتراکی)
- `getUpdates` چت‌هایی که ربات در اون‌ها پیام دیده رو پیدا می‌کنه: گروه دورهمی، یا چت خصوصی هر نفر
- `sendMessage` یادآوری گروهی یا پیام جدا برای هر بدهکار می‌فرسته
- درخواست‌ها **فرم‌انکود** فرستاده می‌شن، چون با JSON مرورگر یک preflight می‌فرسته که تلگرام جواب نمی‌ده

## پیامک (`js/sms.js`)
- **دستی:** لینک `sms:<شماره>?&body=<متن>` اپِ پیامکِ خود گوشی را با متن آماده باز می‌کند. رایگان و از شماره‌ی خود کاربر.
- **خودکار:** پنل‌های کاوه‌نگار و SMS.ir از مرورگر قابل فراخوانی‌اند (هر دو CORS باز دارند). کلید API فقط در `localStorage` همان دستگاه ذخیره می‌شود.
- شماره‌ی موبایل افراد **داخل لینک اشتراکی نمی‌رود**؛ فقط روی دستگاه برگزارکننده می‌ماند.
- متن پیامک کوتاه نگه داشته می‌شود و لینک به‌صورت اختیاری اضافه می‌شود، چون طول پیامک هزینه دارد.

## نکته
اپ هیچ پولی جابه‌جا نمی‌کنه. فقط می‌گه کی به کی چقدر بده و شماره کارت رو کپی می‌کنه.
